# Ready Tier (`ready/`)

This directory is for components in the **ready** maturity tier of Oxygen-Labs.

## What acceptable code goes here?
- **Upstream-Ready Work:** Components that have left the experimental and testing phases and are considered ready to leave the lab.
- **Requirements for Ready Code:**
  - Intended behavior is thoroughly documented.
  - Relevant automated checks, tests, and build validations pass successfully.
  - Known limitations and scope are explicitly stated.
  - Code quality, adherence to KDE coding standards, and architectural design are mature enough for upstream review or integration (while still acknowledging this is a lab environment, not a guarantee of upstream acceptance).

## Strict Code Quality & Review Policy
- **Absolute Prohibition of Unreviewed AI Code ("Vibecoding"):** This tier is **even more restrictive**. Absolutely **no** "vibecoded", non-human-reviewed, or superficially inspected code is permitted. 
- **Full Human Comprehension:** Every contributor must fully understand every architectural decision, logic flow, and implementation detail. Code must pass rigorous human peer review, verification, and maintainability checks before entering the `ready/` tier.
